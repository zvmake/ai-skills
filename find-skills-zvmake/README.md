# find-skills-zvmake

Навык для безопасного поиска, объективного сравнения и контролируемой установки навыков ИИ-агентов.

## Зачем нужен этот навык

Стандартный поиск и установка навыков через `npx skills add` слепо доверяет сторонним репозиториям и счётчикам скачиваний. Злоумышленник может встроить в `SKILL.md` или вспомогательные скрипты:
- **Indirect Prompt Injection** — скрытые инструкции, заставляющие агента во время чтения или работы выполнить вредоносную команду;
- **Кражу секретов (Exfiltration)** — чтение `.env`, переменных окружения `process.env`, SSH/AWS-ключей и отправку их на внешние серверы;
- **Скрытые бэкдоры** — обфусцированный код (`base64`, `eval`), невидимые Unicode-символы, скрытые dotfiles или запуск непроверенных пакетов через `npx -y`.

`find-skills-zvmake` решает эту проблему за счёт карантина, изолированных субагентов-аудиторов и жёсткого запрета на исполнение любых инструкций до одобрения пользователем.

---

## Как работает навык (6 шагов)

1. **Мульти-источниковый поиск:**
   Поиск кандидатов идёт сразу по 7 источникам.

2. **Изолированный карантин:**
   Топ 3–5 кандидатов скачиваются во временную папку карантина с отключёнными git-хуками и удалением каталога `.git`. Никакие скрипты установки не запускаются.

3. **Параллельный построчный аудит субагентами:**
   На каждый скачанный навык запускается отдельный субагент в режиме **только чтения** (`read`, `glob` с `hidden: true`, `grep`).
   - Основной агент не засоряет свой контекст и полностью изолирован от потенциальных промпт-инъекций внутри сырых файлов.
   - Субагент построчно проверяет все файлы (включая скрипты, скрытые файлы и HTML-комментарии) и возвращает стандартизированный отчёт с вердиктом и оценкой качества по 30-балльной шкале:
     - **Точность (Accuracy):** 0–10
     - **Полнота (Completeness):** 0–10
     - **Практическая польза (Utility):** 0–10

4. **Сравнительная таблица и рекомендация:**
   Все небезопасные навыки блокируются (по ним выводится предупреждение с указанием файла и строки уязвимости). Безопасные навыки ранжируются по итоговому баллу и выводятся в сравнительной таблице, где на первом месте стоит лидер с пометкой **⭐ Рекомендуется**.

5. **Подтверждение пользователя (Approval Gate):**
   Агент никогда не устанавливает навык сам. Он запрашивает у пользователя:
   - какой из проверенных навыков установить;
   - в какой каталог выполнить установку: `~/.agents/skills/` или любой другой указанный путь.

6. **Чистая установка из карантина и отчёт:**
   Выбранный навык копируется напрямую из проверенной папки карантина в целевой каталог (что исключает подмену пакета в сети между проверкой и установкой), карантин очищается, а пользователю выводится полный путь установленного навыка.

---

## Установка самого навыка `find-skills-zvmake`

Скопируйте каталог `find-skills-zvmake` в ваш глобальный каталог навыков.

## Структура каталога

```text
find-skills-zvmake/
├── SKILL.md     # Инструкция для ИИ-агента
└── README.md    # Описание навыка для разработчиков и пользователей
```
