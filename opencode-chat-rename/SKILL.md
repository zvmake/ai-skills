# Переименование чата в opencode

## Назначение

Чат в opencode V2 — это сессия; переименование чата — это установка `title` текущей сессии.
Операция штатная: инструмент Code Mode `tools.opencode.session_rename` (пространство
`opencode`). Вызванный **без `sessionID`**, он меняет title **текущей** сессии. Permission-запроса инструмент не делает.

## Порядок действий

1. **Определи имя — строго по правилу:**
   - Пользователь **явно назвал имя** («назови чат "Разбор продакшена"», «имя = ветка git»,
     «имя чата = номер задачи» — номер задачи агент берёт из контекста диалога) — используй
     это имя; для «ветка git» выясни ветку сам (`git branch --show-current`).
   - Пользователь **не назвал имя** («переименуй чат») — **запроси имя у пользователя**
     (задай вопрос; не подставляй имя ветки и не выдумывай), дождись ответа и только тогда
     переименовывай.
2. **Вызови инструмент** без `sessionID`:

   ```js
   const { sessionID, title } = await tools.opencode.session_rename({ title: "Новое имя" });
   ```

   Вернётся id текущей сессии и установленное имя — по ним удобно подтвердить результат.
3. **Подтверди пользователю** новое имя чата одной строкой.

## Если инструмента нет

Скилл покрывает opencode V2. Если инструмент недоступен (среда без Code Mode), тот же
механизм доступен через штатный CLI:

```bash
opencode api session.update --param sessionID="$OPENCODE_SESSION_ID" --data '{"title":"Новое имя"}'
```

`OPENCODE_SESSION_ID` — id текущей сессии, его выставляет opencode командам из чата.

**Для opencode V1 скилл не предназначен:** в документации V1 нет ни `session_rename`, ни
команды `opencode api`, а серверный API V1 несовместим с V2. Не изобретай обходные пути
и не правь БД — сообщи пользователю, что нужен другой инструмент.

## Запреты

- **База данных и SQL — не трогать.** Никаких `UPDATE` в opencode.db: это ломает учёт
  параллельных чатов и не нужно — переименование штатно.
- **Чужие сессии — не переименовывать.** Инструмент умеет менять сессию по `sessionID`,
  но этот скилл — только про текущий чат.
- **Имя — только от пользователя.** Автоподстановок нет (исключение — «имя = ветка git»
  и «имя = номер задачи», где имя задано контекстом диалога).
- **Ничего не сработало** — сообщи пользователю; не импровизируй и не правь БД вручную.

## Примеры

**Пример 1 — явное имя:**
Ввод: `назови этот чат «Разбор продакшена»`
Действие: `tools.opencode.session_rename({ title: "Разбор продакшена" })` → подтвердить.

**Пример 2 — «имя = ветка git»:**
Ввод: `переименуй чат в имя ветки`
Действие: агент выясняет ветку (`git branch --show-current`) → `session_rename({ title: "feature/payments" })`.

**Пример 3 — имя не названо:**
Ввод: `переименуй чат`
Действие: агент спрашивает «Какое имя задать чату?», дожидается ответа и переименовывает.

**Пример 4 — шаблон «имя чата = номер задачи»:**
Ввод: `Переименуй текущий чат, «имя чата = номер задачи»` (номер берётся из контекста диалога)
Действие: `session_rename({ title: "TASK-004" })`.
