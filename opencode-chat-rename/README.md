# opencode-chat-rename

Скилл для ИИ-агента, который переименовывает чат (сессию) в **opencode V2**
штатным способом — без правок базы, без поиска чата и без SQL.

## Какую проблему решает

Чат в opencode — это сессия, а его имя — это `title` сессии. Переименование
штатно доступно через инструмент Code Mode `tools.opencode.session_rename`
(пространство `opencode`). Вызванный **без `sessionID`**, он меняет title
**текущей** сессии и не запрашивает permission.

Скилл избавляет агента от соблазна лезть в `opencode.db` через SQL: правка БД
ломает учёт параллельных чатов и не нужна.

## Как это работает (правило имени)

1. **Пользователь явно назвал имя** («назови чат "Разбор продакшена"») — агент
   сразу переименовывает.
2. **Имя задано контекстом диалога** — разрешены два шаблона:
   - «имя = ветка git» → агент сам выясняет ветку (`git branch --show-current`);
   - «имя = номер задачи» → номер берётся из контекста диалога.
3. **Имя не названо** («переименуй чат») — агент **сначала спрашивает имя** у
   пользователя, дожидается ответа и только потом переименовывает.
   Автопостановок и выдуманных имён нет.

После переименования агент подтверждает новое имя одной строкой.

## Когда скилл срабатывает

Триггеры: «переименуй чат», «переименуй сессию», «смени имя этого чата»,
«назови чат как ветку git», «имя чата = имя ветки», «имя чата = номер задачи» —
или просьба задать чату любое явное имя.

Не применяется к редактированию сообщений и содержимого чата, а также к
сессиям других проектов.
