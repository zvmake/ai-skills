# opencode-chat-rename

Скилл для ИИ-агента, позволяющий переименовывать текущий чат (сессию) в **opencode V2** штатным способом — без прямого доступа к базе данных, SQL-запросов и лишнего поиска идентификаторов.

## Какую проблему решает

В opencode чат представлен объектом сессии, а его видимое название хранится в поле `title`. Штатный инструмент Code Mode — `tools.opencode.session_rename` (пространство `opencode`). Если вызвать его **без параметра `sessionID`**, он сразу обновляет заголовок **текущей** сессии и не запрашивает лишних подтверждений доступа.

Скилл предотвращает попытки агента лезть напрямую в `opencode.db` через SQL: ручная правка базы нарушает целостность данных, ломает учёт параллельных сессий и здесь попросту не нужна.

## Правила выбора имени

1. **Пользователь явно назвал имя** («назови чат "Разбор продакшена"») — агент
   сразу переименовывает.
2. **Имя задано контекстом диалога** — разрешены два шаблона:
   - «имя = ветка git» → агент сам выясняет ветку (`git branch --show-current`);
   - «имя = номер задачи» → номер берётся из контекста диалога.
3. **Имя не названо** («переименуй чат») — агент **сначала спрашивает имя** у
   пользователя, дожидается ответа и только потом переименовывает.
   Автопостановок и выдуманных имён нет.

После успешного переименования агент лаконично подтверждает результат одной строкой.

## Триггеры вызова

Скилл активируется фразами:
* *«переименуй чат»* / *«переименуй сессию»*;
* *«смени имя этого чата»*;
* *«назови чат как текущую ветку git»* / *«имя чата = имя ветки»*;
* *«имя чата = номер задачи»*;
* любой прямой просьбой задать чату конкретное название.

## Границы применимости

Скилл работает исключительно с заголовком текущей сессии:
* не затрагивает текст сообщений и историю диалога;
* не переименовывает сессии других проектов или параллельные чаты.
